📖 Endpoints Disponibles

🎬 Películas

  • GET /api/movies/popular - Películas populares
  • GET /api/movies/genre/:id - Por género (28=Acción)
  • GET /api/movies/:id - Detalles
  • GET /api/movies/search-omdb/:query - Buscar en OMDb

📺 Series

  • GET /api/series/popular - Series populares
  • GET /api/series/search-tvmaze/:query - Buscar TVMaze
  • GET /api/series/tvmaze/:id/episodes - Episodios

📡 TV En Vivo

  • GET /api/tv/live-channels - Todos canales (IPTV)
  • GET /api/tv/channels/:country - Por país
  • GET /api/tv/epg/:channel - Guía de TV

🔍 Búsqueda

  • GET /api/search?query=... - Búsqueda multi
  • GET /api/search/omdb?query=... - Buscar OMDb

📚 Fuentes de Datos

  • TMDB: Películas y series populares
  • TVMaze: Series con episodios
  • OMDb: Películas clásicas
  • IPTV Org: 60,000+ canales de TV en vivo

⚙️ Configuración API

⚠️ IMPORTANTE: El backend debe estar corriendo en http://localhost:3000

🚀 Para iniciar el backend:

cd backend
npm start

🔑 API Keys Requeridas:

  • TMDB API Key: Obtener gratis - Agregar en backend/.env
  • OMDb API Key: Obtener gratis - Agregar en backend/.env

✅ APIs Gratuitas (Sin key):

  • ✓ IPTV Org - 60,000+ canales en vivo
  • ✓ TVMaze - Series completas
  • ✓ OpenSubtitles (próximo)
💡 Tip: Prueba primero los endpoints que no necesitan API Key (IPTV, TVMaze)
