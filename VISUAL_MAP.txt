PASO 1️⃣  Backend (5 minutos)
─────────────────────────
$ cd backend
$ npm install
$ npm start

Verás:
🚀 KeplerTV API corriendo en http://localhost:3000

PASO 2️⃣  Obtener API Key (5 minutos)
──────────────────────────────
1. Ve a: https://www.themoviedb.org/settings/api
2. Crea cuenta (gratis)
3. Solicita API Key
4. Edita backend/.env y pega tu key

PASO 3️⃣  Frontend (10 minutos)
────────────────────────────
$ cd mobile
$ npm install
$ npm run ios    # o: npm run android
